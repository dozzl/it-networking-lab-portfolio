# Active Directory users and groups

**Context:** Windows administration coursework.

## Objective
Practise organizing user accounts and groups within Active Directory organizational units (OUs), and inspect group membership.

## Documented exercise
- The submission discusses organizational units for three locations and domain-local security groups.
- It asks for membership and user-property checks using Active Directory management tools and PowerShell.
- A personal note explains moving groups to an earlier folder for consistency with related access groups.
