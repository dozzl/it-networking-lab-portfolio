# PowerShell user administration

**Context:** Windows Server academic lab.

## Objective
Practise conditional logic and adapting existing PowerShell scripts for domain user administration.

## Documented exercise
- Tested variables, conditional statements and input handling in PowerShell.
- The lab included modifying existing scripts and CSV data for bulk user creation in a domain.
- The written answers discuss handling duplicate usernames and the purpose of quoting values in CSV fields.
- An exercise using `switch` showed why a `break` is needed to stop later matching cases from overwriting a result.

## Evidence and limitations
The user-creation scripts were supplied as part of the course exercise. The source includes requested screenshots but the extracted text does not show the actual screenshots or prove every user account was created. No course-supplied code is reproduced in this record.
