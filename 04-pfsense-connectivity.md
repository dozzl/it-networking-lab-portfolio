# pfSense virtual router: connectivity investigation

**Context:** CSN305 virtual networking lab.

## Objective
Explore a virtual router and investigate connectivity between virtual machines.

## Investigation
The written lab note describes a case in which one PC could ping but another could not. During the investigation, the network adapter was found to be set to host-only. The exercise also covered pfSense interfaces, firewall rules and ping tests across the virtual network.

## What this demonstrates
Checking a virtual machine's network attachment is a useful early step when investigating connectivity. The report records the identified adapter setting; the screenshots need further review to establish the final outcome for every test.
